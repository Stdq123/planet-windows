## 已通过的检查

发布准备的共享质量检查通过，包括 250 个 Bun 测试、禁用结果缓存的 Go 测试、Go 格式与静态分析、TypeScript 检查及前端生产构建；依赖安全扫描与安装器构建通过。上述原生 workflow 同时执行共享检查、安全扫描、构建与安装包审计。

该候选的 `audit.json` 记录十项 payload 与独立文件摘要一致，两份 NSIS 生成的卸载器摘要一致，Kubo 许可收集待审计数为零。Kubo 已收集 241 个模块的许可证据；许可材料收集和包内摘要核验不等于完整法律判断。全部五个内置模板继续保留，按维护者决定不设置模板待审发布门槛，保留上游来源、署名及已有许可文本。

对应源码准备、ZIP 校验与修改 Go 库后重新链接已有工程验证：此前提交 `a642e83361f3d070beb3fe74e553574757663721` 的源码包在 Git 仓库外解压，使用包内 vendor 重建；修改 go-ethereum 后，程序的只读 `--planet-version` 运行返回成功并输出实验标记，锁文件保持不变。记录为 `source-relink-proof.json`，源码 ZIP 摘要为 `041a13cec2f0dcf65db3e826defb5cc79bf5ece14cde97943aeaf7d62d866a02`。该实验程序不用于发行，这份先前工程证明也不替代最终标签提交的源码清单、重建验证或包摘要。方法见[源码与重建说明](rebuilding-release.md)。
