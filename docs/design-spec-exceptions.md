# 设计规范偏差与当前实现映射

记录日期：2026-11-06。依据为《基于 Interface Atlas 的界面设计规范》1.0（同日版本）及所提供合规报告第五节。本记录对照规范的默认参数，说明当前桌面写作界面保留的选择与尚未统一的实现，不重新进行全应用审计，也不声明完整合规。

现有方向来自 [Windows / Fluent 设计参考](../windows/docs/uiux-design-references.md)和[石墨色写作台](uiux/figma-writing-workspace.md)。下表的原因说明本批为何保留当前布局，不表示每个历史字面值都曾经过统一设计。旧[琥珀色概览文档](uiux-dashboard-design.md)仅作历史记录。

## 八类默认参数偏差

| 类别与规范默认 | 当前场景与选择 | 原因 | 影响范围与保留问题 |
| --- | --- | --- | --- |
| 间距：4px 基准，优先 rem | 旧文档自述 8px；实际混用 6、7、9、10、13、14、18、22px 等间距，并非严格 4px 或 8px 网格。 | 本批保留导航密度、写作宽度和现有对齐，避免把局部视觉修复扩展为全局尺度改造。 | 导航、概览、编辑器和对话框均受影响。零散值与缺少统一间距 token 是技术债；不能用“8px 设计系统”将其视为已统一。 |
| 控件：40px；触屏目标 44–48px | 常见按钮和输入采用 32、34、36px，部分图标按钮为 24–32px。 | 以鼠标、键盘为主的桌面写作任务保留紧凑操作区和可见内容量。 | 导航、编辑工具栏、概览与表单沿用当前尺寸；这不是触屏优化承诺。实际可点击区域仍须按适用的目标尺寸与间距要求验证，不能从视觉高度推定通过。 |
| 字号：12/14/16/20/24/32/48 | 常见功能文字使用 12–16px，概览标题 24px，编辑/阅读标题约 24–28px；另有 9–11px 和 18/19/22/30px 等局部值。 | 桌面工具以内容和操作为主，不需要营销页面的 32/48px 展示标题；保留系统字体和当前写作层级。 | 全应用尚未形成单一字号 token 阶梯；小字号、局部越档与缩放后的可读性仍待逐项收敛，不能因密度取舍降低必要文字对比度。 |
| 圆角：4/8/12/16/9999px | 导航与概览控件常用 6px，写作控件 8px；概览入口弹层 10px，通用对话框 16px，其他局部值仍存在。 | 保留紧凑导航与较大写作/弹层容器的现有几何，避免本批改变布局和交互区域。 | 6/8/10/16px 不是已统一的全局阶梯；同级控件混用与残留字面值仍是技术债，后续应按组件归并。 |
| 边框：普通 1px | 侧栏分隔、键帽和工具浮层使用 0.5px；侧栏搜索、网关选项仍保留 0.5px 几何，其余多为 1px。 | 沿用桌面界面的轻分隔，并在本批保留尺寸；必要边界通过专用控件颜色与装饰线区分。 | 0.5px 不是低对比度的豁免。搜索、网关等必要控件边界继续接受 3:1 目标及实际渲染检查；Windows 缩放下细线的可辨识性未实机验证。 |
| 动效：120/240/400ms 与标准缓动 | 当前主要为 120ms 颜色过渡和展开图标旋转，没有 240/400ms 档，未显式声明统一缓动。 | 现有交互以即时反馈为主，没有需要中长时长的场景转场；保留减少动态效果规则。 | 导航、概览和现有控件沿用短过渡；未声明缓动时由浏览器采用默认 `ease`。缺少时长/缓动 token 仍是技术债，不代表已建立完整动效体系。 |
| 断点：48/64rem 默认档 | 使用 1100/1050/940/900/760/700px 媒体查询和 600/520px 工作区容器查询等内容断点。 | 按三栏布局、工具栏、模板列表和阅读区的实际拥挤点调整；工作区可用宽度不等于整个窗口宽度。 | 原生最小窗口宽度为 860px；更小 CSS 查询不构成移动端支持承诺。断点散落和重复仍待集中，旧概览断点表不能作为当前依据，200% 缩放仍未实机验证。 |
| 主导风格：中性或 Atlas 编辑风等可选 | 沿用 Windows / Fluent 参考、石墨控件、暖白表面和系统无衬线字体，不采用 Atlas 的砖红强调色与衬线标题配方。 | 延续已有桌面写作产品的身份、内容层级和系统字体，避免引入另一套品牌皮肤。 | 应用外壳、概览、编辑和应用对话框保持该方向；站点模板保留自身设计。Atlas 编辑风本来就是可选配方，风格选择不能替代通用行为与无障碍要求。 |

## 最小规范到实现映射

颜色角色定义在 [design-tokens.css](../windows/src/design-tokens.css)。下表只映射现有角色与主要使用处，不声称全部旧色值已迁移。

| 规范角色或规则 | 当前 token / 组件 | 范围与限制 |
| --- | --- | --- |
| 页面、表面、强调与选中 | `--pw-canvas`、`--pw-sidebar`、`--pw-card`；`--pw-brand` / `--pw-accent`；`--pw-selection` | [导航](../windows/src/navigation.css)、[概览](../windows/src/dashboard.css)及[写作界面](../windows/src/refinement.css)使用浅色石墨配方。 |
| 主、次、辅助文字 | `--pw-ink`、`--pw-secondary`、`--pw-muted` | 占位文字使用辅助角色；选中行的辅助信息使用更深的次文字角色。不同背景和状态仍须分别检查对比度。 |
| 装饰线与必要边界 | `--pw-line: #e5e1da`；`--pw-control-line: #857a6e` | 前者用于轻分隔；本批涉及的输入、选择、次按钮与视图切换边界使用后者。不能把装饰线直接当作必要控件边界。 |
| 错误、成功、警告 | `--pw-danger: #a13f45`；`--pw-success: #426f58`；`--pw-warning: #946537` | 错误与危险操作读取 danger；`--pw-green`、`--pw-amber` 保留为兼容别名。状态仍需文字或形状线索。 |
| 焦点与选中态 | `--focus` 映射 `--pw-accent`；控件通常使用 2px outline 与 2px offset | 主内容贴边焦点采用内偏移，见[第一批无障碍记录](../windows/docs/design-spec-a11y-batch1.md)。侧栏、文章、草稿、视图切换和[模板选择](../windows/src/layout.css)另有条线或下划线，不能仅以底色表达选中。 |
| 字体、圆角与尺度 | `--pw-font`；`--control-radius: 8px`、`--dialog-radius: 16px` | 系统字体有中文回退；字号、间距及其他圆角仍多为组件字面值，不具备完整基础 token 映射。 |
| 布局、层级与动效 | 导航、概览、写作样式中的媒体/容器查询、局部 z-index 和 120ms transition | 尚无统一断点配置、层级和缓动 token；上表记录原因与影响，不将这些缺口标为完成。 |

## 验收边界

文字对比度、必要控件边界、可见焦点、可操作热区与非颜色状态线索属于独立要求，不能作为风格或默认参数的例外。本批文档不扩展既有检查的覆盖范围：WebView2、Windows 高对比度、Narrator 和 200% 缩放均未实机验证。

仅浅色的支持范围另在 `windows/docs/theme-scope.md` 记录；深色映射尚未实现，强制颜色模式不等于深色主题。后续统一尺度或扩大主题支持时，应同步更新这里的偏差与映射，并重新验证实际受影响的组件。
