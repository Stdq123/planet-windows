## 安装生命周期

| 场景 | 预期 | 结果与证据 |
| --- | --- | --- |
| 干净系统新装 | 成功启动，快捷方式与卸载入口正确 | 未验证 |
| 缺少 WebView2 | 提示可执行的修复步骤，无虚假成功 | 未验证 |
| 已有未知文件的目录 | 保留未知内容，按安装器规则拒绝或处理 | 未验证 |
| 当前支持的旧版升级 | 内容、设置、草稿、附件与身份保留 | 未验证 |
| 程序运行中升级 | 锁守卫生效，无强制关闭与部分覆盖 | 未验证 |
| 升级进程中断后重试 | 同一安装包可恢复，证据不被误删 | 未验证 |
| 同包再次安装 | 幂等行为符合升级协议 | 未验证 |
| 降级或同版本不同包 | 拒绝不受支持的操作 | 未验证 |
| 卸载及重新安装 | 只处理自有文件，用户数据按承诺保留 | 未验证 |
