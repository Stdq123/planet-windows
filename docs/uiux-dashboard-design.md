# 工作区概览 UI/UX 设计与验收

> 已被 2026-11-06 的石墨写作台取代，仅作历史记录；当前设计以 [docs/uiux/figma-writing-workspace.md](uiux/figma-writing-workspace.md) 与 [windows/src/design-tokens.css](../windows/src/design-tokens.css) 为准。本文保留早期琥珀色概览迭代的设计和当时验收，其 8px 网格、48px 控件基线、旧焦点、旧断点及旧测试结果不能作为当前实现的验收证据。当前参数偏差与最小映射见[设计规范偏差记录](design-spec-exceptions.md)。

本次范围是所有站点启动概览、共享侧栏，以及概览打开的搜索与创建入口。保持浅色侧栏，使用现有 Go/MyGo/TypeScript，不引入 React 或另一套组件库。

## 检查依据与问题

当前轮次实拍：原生应用概览、1280px 本地演示概览及侧栏工具弹层。原生画面仅在本机留存，不上传用户内容；下文公开截图均使用演示数据。

1. 核心统计位于大面积写作横幅之后，视觉优先级与总览用途不符。
2. 侧栏底部的导航箭头、向上弹出的工具菜单、内部文章入口的外链箭头混用，图标盒子也有 12/16/20px 多种规格。
3. 边距出现 4/12/20px；卡片、图标、列表日期的基线和边缘不统一。
4. 主按钮、选中态、焦点各用不同颜色；缺少统一的按下状态。
5. 搜索只在侧栏，顶栏缺少稳定的搜索和工作区身份位置。

参考 BoardUI 的 [Sidebar](https://www.boardui.com/components/sidebar) 和 [Stat Cards](https://www.boardui.com/components/stat-cards)：采用统一尺寸的图标与计数槽位、明确的选中态、轻边框，以及固定的标签/数值层级。保留 Planet 的真实本地内容指标；不移植财务示例、付费模板或 React 组件源码。

## 一、视觉基调与设计系统

### 颜色

| 角色 | Hex | 用途 |
| --- | --- | --- |
| 品牌主色 | #F2C94C | 主按钮、重点操作 |
| 品牌悬停 | #E6BA35 | 主按钮 Hover |
| 品牌按下 | #D5A728 | 主按钮 Active |
| 品牌深色 | #8A641B | 焦点实线、选中图标和文字 |
| 品牌浅色 | #FFF3CC | 选中背景与写作入口底色 |
| 页面背景 | #F4F6F8 | 内容区画布 |
| 侧栏背景 | #FAFBFC | 浅色共享导航 |
| 卡片背景 | #FFFFFF | 统计、列表、服务面板 |
| 文本主色 | #202536 | 标题、正文、黄色按钮文字 |
| 文本辅助色 | #616B7D | 日期、标签、说明 |
| 轻边框 | #E0E5EC | 卡片分隔与弹层描边 |
| 控件边框 | #A8B2C2 | 输入/选择控件边界 |
| 行悬停背景 | #F2F5F8 | 可点击内容行 |
| 行按下背景 | #E8EDF3 | 列表和次按钮按下 |
| 成功 / 待处理 / 错误 | #387C63 / #8A641B / #B34E4E | 状态文字与状态点同时使用 |

普通文字以至少 4.5:1 为验收目标，焦点保持可见；黄色按钮使用深色文字。参照 [W3C Contrast Minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) 和 [Focus Visible](https://www.w3.org/WAI/WCAG22/Understanding/focus-visible.html)。这不是对全应用的 WCAG 认证声明。

### 字体

使用 `Segoe UI, Microsoft YaHei, sans-serif`，兼顾 Windows 拉丁文字与中文，不依赖在线字体。Inter 可作为以后品牌字体迁移的选项，本轮不混用。

| 级别 | 字号 | 字重 | 行高 |
| --- | --- | --- | --- |
| H1 页面标题 | 24px | Bold 700 | 32px |
| H2 模块标题 | 18px | Medium 600 | 24px |
| Body 正文 / 操作 | 14px | Regular 400；强调 600 | 24px |
| 辅助文字 | 12px | Regular 400；标签 500 | 16px |

统计值复用 24px/32px、700，并启用等宽数字。仅图标可使用 16/20px 字形，不能把它们作为额外文字字号。长标题最多两行，保留完整 title 提示。

### 空间与卡片

采用 8px 基础单位：小间距 8px、组件间距 16px、模块间距 24px、宽屏页面边距 32px；紧凑窗口页面边距 16/24px。卡片统一 Padding 24px，紧凑卡片/列表项 16px，控件 Padding 8px 16px。0 值、边框线宽、焦点描边和图标绘制不属于布局间距；弹性对齐的 auto 留白不强制量化。

面板圆角 16px、按钮与输入框 8px；卡片无阴影，仅 0.5px 轻边框。浮层需要与底层区分时使用 `0 8px 16px #20253614`。不加左侧彩条；不依赖阴影表达按钮是否可点。

## 二、布局与模块

顺序为：浅色侧栏 → 顶部标题/工具栏 → 四项核心数据 → 紧凑写作入口 → 左侧草稿和最近文章 / 右侧站点与服务。核心数据先进入视线；创建、刷新和服务查询作为辅助操作。

侧栏图标使用 24×24px 固定槽位，图标与文字 Gap 8px；条目高至少 48px，左右内边距 8px，加侧栏外内边距 16px，图标左缘统一在 24px。计数和展开图标占据右侧独立槽位。选中态使用浅琥珀底色及深色文字，Hover 不改变行高。

侧栏 IPFS 是打开状态面板，不使用“进入下一级”的右箭头；工具菜单向上弹出，收起时使用向上 Chevron，展开后反向；访问统计在原位展开，使用向下 Chevron。内部文章跳转使用向右 Chevron，外链箭头仅留给真正的外部链接。

顶部标题居左，搜索入口、刷新、创建和工作区标识共用一条 48px 控件基线，彼此 Gap 16px。搜索入口打开已有搜索对话框，保留 Ctrl+F。应用没有账号系统：右侧当前显示本地工作区标识而非虚构用户头像；若未来接入真实账号，头像采用 32×32px 圆形，在同一 48px 行中垂直居中，不改变操作区边缘。

数据区宽屏四等列，列 Gap 16px；每张卡片相同内边距、标签行高和数字基线。标签与数值左对齐，32px 图标容器放在标签行右端，避免整片饱和颜色抢夺内容。

草稿区两列，卡片 Gap 16px；文章行使用固定缩略图槽位、弹性标题列、120px 日期列和 16px 方向图标。无缩略图时用站点首字，不添加品牌图案。只显示真实可用的站点名和修改日期，不补造阅读/点赞/评论指标。所有模块外缘、标题起点、内容起点以同一网格对齐。

侧栏品牌与页面标题共用 48px 顶部行，并随页面边距使用 32/24/16px 顶部留白；单行工具栏下，概览导航与统计区上缘对齐。文章缩略图左缘与模块标题对齐，宽屏日期对齐文章首行基线；窄窗日期仍排在标题下方。站点列表首尾不重复叠加面板留白。IPFS 与访问统计共用 32px 图标槽和 16px 图文间距，说明文字与标题左缘一致。

## 三、交互与反馈

- Hover：列表背景 #F2F5F8；主按钮 #E6BA35；次按钮浅灰，阴影不跳动。
- Focus：输入/选择控件被点击即显示 2px #8A641B 实线与 4px `#F2C94C40` 柔和外环；按钮、菜单在键盘聚焦时采用相同视觉语言。
- Active：按钮颜色变深至 #D5A728，列表/次按钮至 #E8EDF3；不缩放，保持对齐和点击热区。
- 反馈：加载、读取失败、空工作区和统计未配置继续使用真实状态。失败不显示虚假的零值；禁用按钮不响应 Hover/Active。
- 动效：仅背景、边框和焦点颜色作 120ms 过渡；展开图标旋转 120ms。尊重 reduced-motion；没有位移动画。

## 四、响应式

| 视口宽度 | 布局 |
| --- | --- |
| >1440px | 256px 完整侧栏；主内容居中；统计四列；内容和 320px 服务栏并排；页面 Padding 32px |
| 1201–1440px | 240px 侧栏；统计四列；内容和 288px 服务栏并排；页面 Padding 24px |
| 1024–1200px | 224px 侧栏；服务区移到列表下方，允许两列；搜索和辅助操作按空间换行 |
| 860–1023px | 208px 侧栏保留标签；统计两列；主内容与服务单列；页面 Padding 16px |

原生应用最小宽度为 860px。本轮验证桌面窗口布局与放大等效视口；不把未实现的移动抽屉导航标为完成。

## 验收记录

本轮使用真实源代码和隔离的合成 bridge 数据进行 IAB 渲染测试；测试数据不进入产品构建。原生旧版截图用于确认真实入口，新版 Windows 构建用于原生启动复核。

### 流程与证据

1. 打开原生概览，并在隔离浏览器打开侧栏工具，记录现有问题；另捕获同源演示基线。
2. 依次检查 1600×1000、1280×900、1024×900、860×900 CSS 视口，核对截图与计算样式。
3. 打开工具菜单，用 Escape 收起；打开搜索，检查焦点，关闭后验证返回搜索按钮；用 Ctrl+F 再次打开。
4. 检查创建表单、长标题、无站点状态、统计未配置提示，以及指针悬停/按下反馈。
5. 运行阴影裁切审计、项目质量检查和原生构建。

### 色彩核验与边界

正文 #202536、辅助文字 #616B7D 在白色卡片和浅灰画布上满足 4.5:1 目标；黄色主按钮配深色文字。侧栏选中文字 #8A641B / #FFF3CC、成功/待处理/失败文字在白卡上也达到普通文字对比度目标。图标之外还使用文字说明发布状态，不仅依赖颜色。

本次范围不包含编辑器、阅读器和全部高级设置页面的重新设计，也不宣称全应用无障碍认证。没有账号系统，因此使用“本地工作区”身份标识；没有可用的点赞/评论统计，因此不造数据。原生应用最小宽度 860px，移动抽屉导航不属于本轮交付。构建产物仍为未签名的开发快照，静态 payload 审计不替代安装、升级、卸载和外部服务验收。
