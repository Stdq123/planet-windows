Pinnable 固定服务

站点发布成功后，核对服务报告的 IPNS 一致才会自动请求固定；服务尚未报告身份时可手动确认并请求。此处保存的地址由当前 Windows 用户加密保护，不会自动加入备份。导入的原版备份可能仍保留其原有配置，导回 Mac 后可能重新生效。

Telegram 同步

站点发布成功后，将文章的标题、摘要和链接同步到群组或频道。首次同步包括当前站点的全部历史文章，跳过页面和草稿；修改文章后会更新已有消息。

先通过 BotFather 创建机器人，将其加入目标群组或频道。频道需授予机器人管理员发消息权限，群组需允许机器人发消息。

配置和同步记录只保存在本机。保存仅验证机器人和目标，不会发送消息；下一次发布成功后开始同步。

外部发布

配置只保存在本机，Cloudflare 令牌由当前 Windows 用户加密保护。自动发布仅在成功发布 IPNS 后执行；也可手动发布当前已保存内容。

播客设置

包含音频的文章会生成 podcast.xml。封面选择后立即保存并发布；其他设置保存后发布。

域名与社交资料

域名须自行配置解析与托管。ENS 域名复制链接使用所选网关；RSS 使用 eth.limo。保存后将重新发布站点。

同步到 X

将文章标题与链接发布到 X。需要具有 Read + Write 权限的 X 应用，调用 API 可能产生费用。凭据仅保存在本机，不会显示或导出。

仅启用后新建的文章会在发布成功后自动同步；历史文章需手动同步，已同步文章不会重复发布。

已有配置时，四项全部留空可保留原凭据；更换凭据时请完整填写四项。

文章同步记录

Filebase 和 Plausible

Filebase 在站点发布后为每个新版本创建独立固定请求，旧固定项不会自动删除，可能产生存储费用。Plausible 可输入网站安装页面提供的 pa- 开头脚本 ID；留空时使用原版兼容脚本。重新发布后生效，可查询统计。新配置的凭据由当前 Windows 用户加密保护，不会自动加入备份；原版导入的凭据仍可能明文保留在归档和备份中。

自定义代码与发布偏好

在生成的站点 HTML 中注入自定义代码（如统计脚本、样式表或挂件），并配置发布偏好。保存后重新发布站点生效。

Web3 捐赠与 Juicebox 设置

配置以太坊打赏地址、Juicebox 项目徽章以及文章附件 `nft.json` 元数据生成；保存后重新发布站点生效。

文章设置

保存后会重新发布站点。更改路径后，原文章 ID 地址仍可使用，旧自定义路径将不再生成。

添加订阅
