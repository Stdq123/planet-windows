Sepia 模板设置

颜色使用六位十六进制格式；保存后需发布站点才能公开生效。

Pinnable 固定服务

站点发布成功后，核对服务报告的 IPNS 一致才会自动请求固定；服务尚未报告身份时可手动确认并请求。此处保存的地址由当前 Windows 用户加密保护，不会自动加入备份。导入的原版备份可能仍保留其原有配置，导回 Mac 后可能重新生效。

Filebase 和 Plausible

Filebase 在站点发布后为每个新版本创建独立固定请求，旧固定项不会自动删除，可能产生存储费用。Plausible 可输入网站安装页面提供的 pa- 开头脚本 ID；留空时使用原版兼容脚本。重新发布后生效，可查询统计。新配置的凭据由当前 Windows 用户加密保护，不会自动加入备份；原版导入的凭据仍可能明文保留在归档和备份中。
